## Why this cutover is required

Fresh issue #154 proved the initial 2.4.5 production-shaped path. Same-delivery
issue #156 then proved target-side managed-draft reuse without a second Codex
execution, but exposed organization defect
`Young-Consultations/.github#83`: the deployed result-writer identity could
not authenticate its own durable receiver journal evidence, causing a second
result forwarding attempt that the source correctly quarantined.

The 3.0.x control-plane line moves the result-writer role to the dedicated
`ai-sdlc-result-writer[bot]` GitHub App while preserving separation from
admission authority. Corrective 3.0.1 repairs the deployed Runtime Preflight
organization-secret metadata audit discovered during that cutover. The live
source sender allowlist is required to exactly match the immutable reviewed
result-writer identity.
