   actionlint, canonical local 29-scenario target conformance and zero-effect
   checks. Current-head **Copilot OR Codex** review must complete without
   unresolved comments. Verify the target's published tag, and check the
   source change does not cause cost-bearing execution.

   `AI-SDLC Runtime Preflight` on attested 3.1.0 control-plane `main`.
   Its read-only gate independently retrieves the `portfolio-tasks@main`
   route job and rejects a wrong/mutable/inaccessible router ref. The old
   `ai-sdlc-v3.0.3` source pin **must** fail this 3.1.0 gate.

   the appropriate audit token. Treat missing independent evidence as FAIL.
   Run the non-mutating immutable REAL-readiness preflight only after this.
4. Before any paid REAL implementation, independently assess outstanding
   [consulting-playbook #93](https://github.com/Young-Consultations/consulting-playbook/issues/93)
   stale task-content baseline risk, and require a **new authorized** human
   delivery with an original identity. The terminal failure from
   [.github #111](https://github.com/Young-Consultations/.github/issues/111)
   must not be replayed or reused for a new cost-bearing call.
5. Only following successful governed live acceptance update the Defect Ledger,
   Engineering Journal, release readiness/acceptance evidence and any affected
   standing AI_CONTEXT files. A green SIM is not evidence of REAL success.
